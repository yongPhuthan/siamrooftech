Project: siamrooftech. Purpose: SEO-focused canvas tent/awning sales website with portfolio and article CMS, built in Next.js (App Router) with Firebase backend and admin UI. Tech stack: TypeScript, Next.js 15, React 18, Firebase (client/admin), MUI v5 + Emotion, Tailwind CSS, Jest. Structure (from repo root): src/ (app + components + lib), public/, docs/, scripts/, .next/ build output. Design docs live under docs/design-system/.
