# Development references

Use the current repository owners and official project documentation for implementation details:

- App routing and server rendering: [Next.js App Router](https://nextjs.org/docs/app)
- Local runtime and bindings: [OpenNext for Cloudflare](https://opennext.js.org/cloudflare)
- Auth and account provisioning: [Better Auth](https://www.better-auth.com/docs)
- Database schema and queries: [Drizzle ORM](https://orm.drizzle.team/docs/overview)
- D1 operations: [Cloudflare D1](https://developers.cloudflare.com/d1/)
- Media persistence: [Cloudflare R2](https://developers.cloudflare.com/r2/)
- Public UI patterns: [design system](../design-system/PUBLIC_UI_DESIGN.md)

For project and article behavior, follow the feature instructions and tests beside their owners. Public routes read published snapshots; private editorial operations use authenticated same-origin APIs.
