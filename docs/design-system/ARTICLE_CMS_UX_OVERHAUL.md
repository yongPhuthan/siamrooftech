# Article CMS UX Overhaul - SEO-first Mobile CMS

## 📋 Overview

**Feature**: SEO-first Mobile CMS สำหรับบทความ
**Context**: แอดมิน/เจ้าของเว็บเขียนและอัปเดตบทความจากมือถือเป็นหลัก โดยเน้นติดอันดับคำค้น
**User Segment**: เจ้าของเว็บ/แอดมินที่เป็นผู้เขียนเอง (ไม่ใช่สายเทคนิค), ใช้งานบนมือถือ iOS/Android
**Primary Keyword**: "กันสาดพับได้"

## 🎯 Core Principles

### 1. Zero-Config SEO
- ตั้งค่าที่จำเป็นให้อัตโนมัติ
- เหลือเฉพาะสิ่งที่ผู้เขียนเข้าใจง่าย
- Auto-generate: slug, meta title/description, alt text, canonical, og tags

### 2. Write-First
- การพิมพ์และแปะ (copy-paste) ต้องลื่นไหลก่อนเรื่องอื่น
- เริ่มเขียนทันทีด้วยช่องเนื้อหาเดียว
- ระบบทำความสะอาดฟอร์แมตอัตโนมัติ

### 3. Mobile-First
- ทุกงานหลักทำได้ด้วยนิ้วเดียว/มือเดียว
- ปุ่มหลักอยู่ในตำแหน่งที่เอื้อมถึง (Fitts's Law)
- โหมดพิมพ์เต็มจอ + แถบเครื่องมือย่อได้

### 4. Guided SEO
- ชี้นำแบบเบา ๆ ระหว่างเขียน
- ไม่รบกวน flow
- แนะนำตำแหน่งใช้คีย์เวิร์ด/คำพ้องแบบนุ่มนวล

### 5. Trust & Guardrails
- ป้องกันข้อผิดพลาด SEO โดยไม่ต้องอธิบายศัพท์เทคนิค
- กัน duplicate title, หัวข้อซ้ำ, ลิงก์เสีย, คำสะกด

## 📊 Laws of UX Applied

### Hick's Law - การลดทางเลือก
- **เดิม**: แบ่ง 3 tabs (พื้นฐาน, เนื้อหา, SEO) ✓
- **ใหม่**:
  - เพิ่ม "Quick Path: เขียน → ตรวจ → เผยแพร่" แบบ 3 ขั้น
  - แนะนำ internal links และหัวข้อย่อยจาก AI
  - Smart defaults ลดการตัดสินใจ

### Fitts's Law - ขนาดและตำแหน่ง
- **เดิม**: Submit button ใหญ่ด้านล่างขวา ✓
- **ใหม่**:
  - FAB (Floating Action Button) สำหรับบันทึกบนมือถือ
  - ปุ่มหลักใช้นิ้วโป้งถึง
  - เมนูสำคัญอยู่ด้านล่าง

### Miller's Law - จำกัดข้อมูล
- **เดิม**: Tags สูงสุด 7 แท็ก ✓
- **ใหม่**:
  - แสดง 5-7 คำแนะนำต่อครั้ง
  - จัดกลุ่ม SEO hints เป็น categories

### Goal Gradient Effect - Progress
- **เดิม**: Progress bar แบบ 3 ขั้น ✓
- **ใหม่**:
  - คะแนนความพร้อม SEO แบบเรียลไทม์
  - เช็กลิสต์ก่อนเผยแพร่พร้อมเปอร์เซ็นต์

### Doherty Threshold - Performance
- Autosave ทุก 3 วินาที
- SERP preview แบบ real-time
- Debounce search suggestions

### Jakob's Law - Convention
- ใช้ Standard Editor Patterns (Markdown/WYSIWYG)
- Logo ที่คุ้นเคยสำหรับ Actions
- Layout คล้าย Medium/WordPress

### Aesthetic-Usability Effect
- Design สะอาดตา, สวยงาม
- Typography ชัดเจน
- Color coding สำหรับ status

```typescript
interface Article {
  // Existing fields
  id: string;
  title: string;
  excerpt: string;
  content: string;
  featured_image?: string;
  category: string;
  author: string;
  published_at: string | any;
  read_time: string;
  tags: string[];
  slug: string;
  created_at?: string | any;
  updated_at?: string | any;

  // SEO fields (existing)
  seoTitle?: string;
  seoDescription?: string;
  seoKeywords?: string[];
  isPublished: boolean;
  viewCount?: number;
  lastModified?: string | any;

  // NEW: Zero-Config SEO fields
  autoGeneratedSlug?: string; // Auto from title
  autoGeneratedMeta?: {
    title: string; // Auto from content analysis
    description: string; // Auto from first paragraph
    keywords: string[]; // Auto extracted
  };

  // NEW: Content Analysis
  contentAnalysis?: {
    readabilityScore: number; // 0-100
    keywordDensity: { [keyword: string]: number }; // %
    headingStructure: string[]; // H1-H6 list
    internalLinks: number;
    externalLinks: number;
    imageCount: number;
    imagesWithAlt: number;
    wordCount: number;
    sentenceCount: number;
  };

  // NEW: SEO Readiness
  seoReadiness?: {
    score: number; // 0-100
    checks: {
      titleOptimal: boolean;
      descriptionOptimal: boolean;
      keywordInTitle: boolean;
      keywordInFirstParagraph: boolean;
      keywordInHeadings: boolean;
      hasInternalLinks: boolean;
      allImagesHaveAlt: boolean;
      noDuplicateTitle: boolean;
      slugOptimal: boolean;
      readabilityGood: boolean;
    };
    suggestions: string[]; // List of recommendations
  };

  // NEW: Topic Coverage (for "กันสาดพับได้")
  topicCoverage?: {
    topics: {
      pricing: boolean; // ราคา
      types: boolean; // ประเภท
      materials: boolean; // วัสดุ
      installation: boolean; // วิธีติดตั้ง
      maintenance: boolean; // การดูแล
      pros: boolean; // ข้อดี
      cons: boolean; // ข้อจำกัด
      faq: boolean; // คำถามพบบ่อย
    };
    coverageScore: number; // 0-100
  };

  // NEW: Autosave & Recovery
  draftVersions?: {
    timestamp: string;
    content: string;
    autoSaved: boolean;
  }[];
  lastAutoSave?: string;

  // NEW: Internal Linking Suggestions
  suggestedInternalLinks?: {
    articleId: string;
    articleTitle: string;
    relevanceScore: number;
    suggestedAnchor: string;
  }[];
}
```

const SerpPreview = ({ title, seoTitle, seoDescription, excerpt, slug }) => {
  const displayTitle = seoTitle || title;
  const displayDesc = seoDescription || excerpt;

  return (
    <div className="serp-preview">
      <div className="serp-title">{truncate(displayTitle, 60)}</div>
      <div className="serp-url">siamrooftech.com › articles › {slug}</div>
      <div className="serp-description">{truncate(displayDesc, 160)}</div>

## 🎯 Acceptance Criteria

✅ **ผู้เขียนสามารถสร้างบทความ "กันสาดพับได้" จากมือถือใน ≤ 10 นาที โดยไม่แตะค่าทางเทคนิค**

✅ **คะแนนความพร้อม SEO เป็น "พร้อมเผยแพร่" โดยแก้ตามคำแนะนำไม่เกิน 3 จุด**

✅ **อัตรา paste-and-clean สำเร็จ (ไม่ต้องแก้ฟอร์แมตเอง) ≥ 90% ของกรณีที่รองรับ**

✅ **ไม่มีข้อผิดพลาดสำคัญ (title ซ้ำ, canonical ผิด, alt ว่าง) ในรอบเผยแพร่**
