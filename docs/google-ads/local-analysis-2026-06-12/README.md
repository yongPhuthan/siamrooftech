# Local Analysis Summary - Siamrooftech Google Ads

## What This Analysis Adds

The old CSV exports are now converted into two operational artifacts:

- [Keyword Launch Map](keyword-launch-map.md)
- [Negative Keyword Candidate Table](negative-keyword-candidates.md)

## Main Findings

- The old account is not a model to copy. It is a source for query demand and leakage patterns.
- Useful launch demand clusters: core retractable awnings, electric/automatic awnings, price/quote intent, fabric/canvas intent, and installation intent.
- Waste-risk clusters: retailer comparison, DIY/how-to, ready-made kit, repair/parts/cleaning, free/second-hand intent.
- The first campaign should prioritize query control over scale.

## Recommended Next Use

Use the keyword map when building ad groups and use the negative candidate table before launch. After launch, update the negative table with real search-term data from the new account.
